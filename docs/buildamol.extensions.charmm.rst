.. _charmm:

CHARMM Extension
================

The `charmm` extension provides tools and interfaces for enhancing molecule compatibility with the CHARMM molecular dynamics environment.
These are functions that used to be part of the core BuildAMol package and have now been moved ot this extension hub for easier access as we are 
continuing to modularize the BuildAMol ecosystem and remove hard dependencies on external software.
